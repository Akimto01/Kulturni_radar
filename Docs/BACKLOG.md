Spojení padá už na úrovni TLS handshake, dřív než přijde jakýkoli obsah. Ověřeno DVĚMA nezávislými způsoby: (a) přímo `openssl`/`curl` z Claude Code — i s vypnutým ověřováním certifikátu (`-k`) spojení opakovaně spadlo („server closed abruptly"); (b) skutečný Chrome prohlížeč přes `claude-in-chrome` ukázal bezpečnostní interstitial, který nejde ani vyfotit, ani přečíst — typické chování Chrome u chyby certifikátu. Web přitom dřív fungoval (Google/Bing ho v minulosti indexovaly, `site:olomouckadrbna.cz kultura` najde reálné články v sekci kultura/akce) — jde tedy pravděpodobně o NEDÁVNOU/dočasnou chybu konfigurace na straně provozovatele, ne o trvalý stav webu. Pokud Anthropic `web_search` tool dělá standardní TLS ověření (rozumný předpoklad), narazil by na PŘESNĚ TUHLE zeď nezávisle na síle formulace doporučení v promptu — žádná úprava promptu tenhle problém nevyřeší, dokud bude web nedostupný.
    **Rozhodnutí:** NEMĚNIT zdroj hned. Počkat ~2–3 týdny, jestli provozovatel web sám neopraví (self-signed cert nesedící na doménu je natolik základní chyba, že jde spíš o přechodný stav než trvalé rozhodnutí). Připomínka k opětovné kontrole (cca konec září 2026): zkusit znovu navštívit web (TLS handshake) + zkontrolovat AKCE, jestli se `olomouckadrbna.cz` objevil jako zdroj.
